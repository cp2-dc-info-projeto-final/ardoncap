# Requisitos Funcionais

- RF1: Cadastrar Usuário
- RF2: Login de Usuário
- RF3: Editar pefil do usuário
- RF4: Excluir perfil do usuário
- RF5: Logout de usuário
- RF6: Marketplace com aba para pesquisa
- RF7: Comprar produtos
- RF8: Sistema deve disponibilizar carrinho
- RF9: Sistema deve disponibilizar CRUD de Produtos
- RF10: Sistema deve disponibilizar opção de avaliação do produto

# Requisitos Não Funcionais

- RNF1: Sistema deve ser fácil de entender e usar
- RNF2: Sistema deve se adaptar a diferentes dispositivos
- RNF3: Não permitir que o Usuário edite e exclua dados de outros usuários
- RNF4: Usuário só pode avaliar produtos após o ato de compra 
- RNF5: O sistema deve ser leve
- RNF6: Não permitir que o usuário visualize dados privados de outros usuários
- RNF7: O sistema deve carregar poucos produtos por vez
